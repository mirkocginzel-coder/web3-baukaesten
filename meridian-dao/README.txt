MERIDIAN DAO — Community/Governance Landingpage-Baukasten
============================================================

Willkommen! Diese Anleitung führt dich in 3 einfachen Schritten
zu deiner eigenen, fertigen Webseite — auch ohne Programmierkenntnisse.

SCHRITT 1 — ÖFFNEN
-------------------
Öffne die Datei "index.html" mit einem einfachen Texteditor
(z.B. Editor/Notepad unter Windows, TextEdit unter Mac).
Rechtsklick auf die Datei -> "Öffnen mit" -> Texteditor auswählen.

Willst du vorher sehen, wie die Seite aussieht: Doppelklick auf
"index.html" öffnet sie direkt in deinem Browser.

SCHRITT 2 — ANPASSEN
---------------------
Im Text der Datei sind alle Stellen, die du typischerweise ändern
willst, mit Kommentaren markiert:

    <!-- ===== HIER ÄNDERN: ... ===== -->

Suche einfach nach "HIER ÄNDERN" (Tastenkombination Strg+F bzw. Cmd+F)
und ersetze die Beispieltexte durch deine eigenen.

Die Statistik-Zahlen (Treasury, Grants, Mitglieder, Proposals) findest
du ganz oben im <script>-Bereich in einem übersichtlichen Block namens
"CONFIG" — dort einfach die Zahlen austauschen.

Farben ändern: Ganz oben im <style>-Bereich, im Abschnitt ":root",
sind alle Farben mit Kommentaren erklärt.

TIPP FÜR ERFAHRENE NUTZER
--------------------------
Die "HIER ÄNDERN"-Kommentare enthalten nicht nur Stellenangaben,
sondern auch kurze Fachhinweise (Farbtheorie, Conversion-Psychologie,
Social-Media-Technik) — auch für alte Hasen lohnt sich ein Blick
in den Code, nicht nur für Einsteiger.

SCHRITT 3 — VERÖFFENTLICHEN
-----------------------------
Sobald du fertig bist, lädst du die Datei "index.html" auf einen
eigenen Webspace/Server hoch — schon ist deine Seite live im Internet.

Kostenlose Optionen zum Hosten (eigene Recherche empfohlen):
- GitHub Pages
- Netlify (Drag & Drop von Dateien)
- Vercel

WICHTIGER HINWEIS
------------------
Diese Vorlage ist eine reine Frontend-Seite (Schaufenster). Der
"Connect Wallet"-Button ist nur optisch — für eine echte Blockchain-
Anbindung (z.B. echtes Voting) braucht es zusätzliche technische
Umsetzung.

Der Code wird kostenlos und ohne Gewährleistung bereitgestellt
("as is"). Nutzung auf eigenes Risiko. Freie kommerzielle Nutzung
und Anpassung ist erlaubt.

Viel Erfolg mit deinem Projekt!
